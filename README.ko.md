# Markdown Diff for AI

*[English](README.md)* | *[日本語](README.ja.md)* | *[中文](README.zh.md)* | *[한국어](README.ko.md)* | *[Español](README.es.md)* | *[Deutsch](README.de.md)* | *[Français](README.fr.md)* | *[Português](README.pt-br.md)*

Markdown Diff for AI는 두 마크다운 파일 간의 변경 사항을 HTML로 완전히 렌더링된 상태에서 시각적으로 비교하도록 설계된 VS Code 확장 프로그램입니다. 문서 구조, 단락, 코드 블록 및 이미지의 차이를 빠르고 직관적으로 파악할 수 있도록 도와주며, 특히 AI가 생성한 수정 사항이나 공동 편집을 검토하는 데 효과적입니다.

## 주요 기능 (Features)

- **AI 에이전트 수정을 위한 UI 최적화**: AI 에이전트가 마크다운 파일을 자율적으로 업데이트할 때 빈번하고 번거로운 차이점 확인이 필요합니다. 이 도구는 거친 줄 단위의 차이점을 생성하는 대신 **블록 수준(단락, 목록, 코드 블록 등)**에서 지능적으로 변경 사항을 비교하는 고도로 최적화된 UI를 제공하여 인간이 AI의 의도를 직관적으로 파악할 수 있도록 합니다.
- **풍부한 Webview 렌더링**: VS Code 내에서 완전히 렌더링된 HTML로 차이점을 표시합니다. 추가된 텍스트는 녹색으로, 삭제된 텍스트는 취소선이 있는 빨간색으로 강조 표시됩니다.
- **🚀 [NEW] 강력한 Git 통합**:
  - 탐색기에서 파일을 마우스 오른쪽 버튼으로 클릭하고 **"Git: HEAD와 비교..."** 또는 **"이전 변경 사항과 비교..."**를 선택하면 Git 기록에 대한 차이점을 즉시 미리 볼 수 있습니다.
  - **커밋 또는 브랜치 선택**: 대화형 `QuickPick` 메뉴를 사용하여 특정 과거 커밋이나 로컬 브랜치를 원활하게 선택하여 현재 파일과 비교할 수 있습니다.
- **세밀한 차이점 (Fine-grained Diff)**: 주요 변경 사항은 블록 교체로 표시되고 사소한 수정은 단어별로 강조 표시됩니다. 코드 블록은 줄 단위로 비교됩니다.
- **이미지 콘텐츠 비교**: 로컬 이미지 파일의 해시를 자동으로 계산합니다. 이미지가 수정되면(파일 경로가 동일하게 유지되더라도) 정확하게 감지되어 상단과 하단 분할 비교 레이아웃으로 표시됩니다.
- **자동 페어링**: 하나의 파일(After 또는 Before)을 선택하면 확장 프로그램이 상대적인 디렉토리 경로를 기반으로 해당 파일을 추론하고 자동으로 선택할 수 있습니다.
- **자동 비교 (Auto-Diff)**: "After" 및 "Before" 파일이 모두 선택되는 즉시 비교가 자동으로 시작됩니다.
- **지우기 (Clear)**: 선택 항목 및 차이점 뷰를 재설정하는 원클릭 지우기 버튼.
- **민감도 슬라이더 (Sensitivity Slider)**: 차이점 일치 알고리즘의 민감도를 실시간으로 조정합니다.
- **다국어 지원**: 일본어 및 중국어와 같은 비영어권 언어를 매끄럽게 토큰화하여 자연스러운 단어 수준의 차이점을 제공합니다. VS Code 기본 UI 언어를 지원합니다.
- **Webview 상태 유지**: 다른 탭으로 전환했다가 돌아올 때 선택 항목과 차이점 결과가 유지됩니다.
- **HTML 정화 (Sanitization)**: 마크다운 파일에 포함된 스크립트를 정리하여 임의의 코드 실행을 방지하고 보안을 보장합니다.

## 사용 방법 (Usage)

1. VS Code의 탐색기를 엽니다.
2. 수정된 마크다운 파일을 마우스 오른쪽 버튼으로 클릭하고 **"Select as After (변경 후로 선택)"**을 선택합니다.
3. 원본(변경 전) 마크다운 파일을 마우스 오른쪽 버튼으로 클릭하고 **"Markdown Diff: Select as Before (변경 전으로 선택)"**을 선택합니다.
4. 자동 페어링이 활성화된 경우 많은 경우 하나의 파일만 선택하면 다른 파일이 자동으로 추론되어 선택됩니다.
5. Webview가 열리고 서식이 풍부한 차이점이 표시됩니다.

*참고: 오른쪽 상단의 "파일 교체" 버튼을 눌러 "변경 후" 및 "변경 전" 파일을 교환할 수도 있습니다.*
