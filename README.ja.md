# Markdown Diff for AI

Markdown Diff for AI は、2つのMarkdownファイル間の変更履歴を、HTMLとしてレンダリングされた状態で視覚的に比較できるVS Code拡張機能です。文章の構造、段落、コードブロック、画像の差分を直感的に把握できるため、AIによって生成・修正された原稿の確認や、共同編集におけるレビュー作業に最適です。

## 主な機能 (Features)

- **レンダリング済みMarkdownの差分表示**: HTMLとしてレンダリングされた状態で差分を表示します。追加箇所は緑色で強調され、削除箇所は赤色の取り消し線で示されます。
- **細粒度な差分抽出 (Fine-grained Diff)**: 大幅な変更はブロック単位での置換として表示し、軽微な変更は文字や単語単位でハイライトします。コードブロックは行単位での比較に対応しています。
- **画像内容の変更検知**: ローカル画像ファイルのハッシュ値を計算することで、ファイル名が同じでも画像の中身が変更されたことを正確に検知し、変更前と変更後の画像を上下に並べて比較表示します。
- **相対パスによる自動ペアリング**: 一方のファイル（After または Before）を選択した際、ディレクトリ階層の相対的な関係を推論し、対応するもう一方のファイルを自動で選択します。
- **Auto-Diff (自動比較)**: After と Before の両方のファイルが揃うと、手動でボタンを押すことなく自動的に差分比較を開始します。
- **Clear (一括クリア)**: 選択状態や差分表示をリセットするClearボタンを搭載しています。
- **Sensitivity (感度調整)**: 差分判定の感度をリアルタイムに調整できます。
- **多言語対応**: 日本語、英語をはじめとする多言語の自然な単語分割に対応しています。UIもVS Codeの言語設定に応じて日本語/英語に切り替わります。
- **Webview状態の保持**: 別のタブへ切り替えて戻ってきた際にも、選択ファイルや差分結果が消えずに保持されます。
- **HTMLサニタイズ処理**: Markdown内に埋め込まれたスクリプト等の任意コード実行を防ぐセキュリティ対策が施されています。

## 使用方法 (Usage)

1. VS Codeのエクスプローラーを開きます。
2. 変更後のMarkdownファイルを右クリックし、メニューから **「Select as After (変更後として選択)」** をクリックします。
3. 元のMarkdownファイルを右クリックし、メニューから **「Select as Before (変更前として選択)」** をクリックします。
4. Webviewパネルが自動的に開き、レンダリングされた差分が表示されます。
5. コマンドパレットから直接実行することも可能です。
6. 必要に応じて、画面上部の「Sensitivity（感度）」スライダーを動かして、差分判定の感度を調整してください。

## Sensitivity について

Sensitivity（感度）は、差分判定の感度を調整するための設定です。`0.0` 〜 `1.0` の範囲を `0.1` 刻みで指定できます。Markdownの内容や比較目的に応じて調整できます。

## 設定項目 (Extension Settings)

本拡張機能では以下の設定項目を提供しています。

* `markdownDiffForAi.defaultSensitivity`: 新しく比較パネルを開いた際に適用されるSensitivityのデフォルト値です。`0` から `1` の数値を指定できます。（初期値: `0.7`）

*※Webviewパネル上でSensitivityスライダーを操作しても、このVS Code設定自体は書き換えられません。*
