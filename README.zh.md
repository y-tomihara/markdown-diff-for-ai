# Markdown Diff for AI

*[English](README.md)* | *[日本語](README.ja.md)* | *[中文](README.zh.md)* | *[한국어](README.ko.md)* | *[Español](README.es.md)* | *[Deutsch](README.de.md)* | *[Français](README.fr.md)* | *[Português](README.pt-br.md)*

Markdown Diff for AI 是一个 VS Code 扩展，旨在直观地比较两个 Markdown 文件在完全渲染为 HTML 状态下的差异。它可以帮助您快速直观地掌握文档结构、段落、代码块和图像的差异，特别适合于审查由 AI 生成的修改或协同编辑。

## 主要功能 (Features)

- **为 AI 代理的修改优化 UI**: 当 AI 代理自动更新 Markdown 文件时，通常需要频繁且繁琐的差异检查。该工具提供了一个高度优化的 UI，它在**块级别（段落、列表、代码块等）**智能地比较差异，而不是生成嘈杂的原始逐行差异，使人类能够直观地理解 AI 的意图。
- **丰富的 Webview 渲染**: 在 VS Code 中将差异显示为完全渲染的 HTML。添加的文本用绿色突出显示，删除的文本用带删除线的红色突出显示。
- **🚀 [NEW] 强大的 Git 集成**:
  - 只需在资源管理器中右键单击文件，然后选择 **“Git: 与 HEAD 比较...”** 或 **“与上一次修改比较...”**，即可立即预览与 Git 历史记录的差异。
  - **选择提交或分支**: 使用交互式 `QuickPick` 菜单无缝选择特定的过去提交或本地分支以与当前文件进行比较。
- **细粒度差异**: 主要更改显示为块替换，而微小调整则逐字突出显示。代码块逐行比较。
- **图像内容比较**: 自动计算本地图像文件的哈希值。如果图像被修改（即使文件路径保持不变），也能被准确检测到并以顶部和底部拆分比较布局显示。
- **自动配对**: 当您选择一个文件（修改后或修改前）时，扩展程序可以推断并根据相对目录路径自动选择相应的文件。
- **自动比较 (Auto-Diff)**: 只要选择了“修改后”和“修改前”文件，比较就会自动开始。
- **清除 (Clear)**: 重置选择和差异视图的一键清除按钮。
- **灵敏度滑块 (Sensitivity Slider)**: 实时调整差异匹配算法的灵敏度。
- **多语言支持**: 无缝标记非英语语言（如日语和中文）以实现自然的词级差异。支持 VS Code 原生 UI 语言。
- **保留 Webview 状态**: 当您切换到其他选项卡并返回时，您的选择和差异结果将被保留。
- **HTML 净化**: 清理 Markdown 文件中嵌入的脚本以防止任意代码执行，确保安全性。

## 使用方法 (Usage)

1. 打开 VS Code 的资源管理器。
2. 右键单击修改后的 Markdown 文件，然后选择 **"Select as After (选择作为修改后)"**。
3. 右键单击原始（修改前）Markdown 文件，然后选择 **"Markdown Diff: Select as Before (选择作为修改前)"**。
4. 如果启用了自动配对，在许多情况下，您只需要选择一个文件，另一个文件将自动被推断并选择。
5. Webview 将打开并显示富文本差异。

*注意：也可以通过按右上角的“切换文件”按钮来交换“修改后”和“修改前”文件。*
